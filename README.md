# Convite — Santos

Um convite em formato de scrollytelling para um fim de semana de aniversário em Santos: mensagens que aparecem conforme a página rola, um avião que desce até o pouso, e a agenda de Sábado e Domingo.

## Rodando localmente

```
npm install
npm run dev
```

Abre em `http://localhost:5173`.

## Stack

React + Vite, com [Framer Motion](https://www.framer.com/motion/) para as animações de scroll.
